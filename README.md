# SteamScope — интеллектуальный Telegram-бот для мониторинга рынка Steam
Telegram-бот для автоматического отслеживания, анализа и краткосрочного прогнозирования цен на внутриигровые предметы Торговой площадки Steam.

 Возможности
-  Добавление предмета в отслеживание по ссылке с Steam Market
-  Визуализация истории цен (графики)
-  Краткосрочный прогноз на основе анализа временных рядов
-  Мгновенные уведомления при достижении заданного порога цены
-  Список отслеживаемых предметов
-  Удаление предметов из отслеживания

 Как это работает
- Fetch-модуль — асинхронно собирает данные с Steam API
- Database — хранит историю цен (SQLite / PostgreSQL)
- Analyzer — фильтрует рыночный шум с помощью медианного фильтра и фильтра Калмана, а также строит краткосрочные прогнозы на основе анализа временных рядов
- Bot — интерфейс в Telegram

 Технологии
- Python 3.11+
- Aiogram (Telegram Bot API)
- Aiohttp (асинхронные запросы)
- Pandas / NumPy (анализ данных)
- SQLite → PostgreSQL
- Git / GitHub
